# CS61A — Structure and Interpretation of Computer Programs

## Projects

- `PJs/cats` — 打字测速 Cats：字符串处理、递归与动态规划
- `PJs/ants` — 塔防游戏 Ants：面向对象编程、继承与多态
- `PJs/scheme` — Scheme 解释器：词法与语法分析、求值器、特殊形式与尾递归优化
